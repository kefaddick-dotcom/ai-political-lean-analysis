# Data

**No participant data is stored in this repository.** Transcripts, chat logs, interview data and coded data stay on secure lab storage under the study's ethics approval.

`example/example_queries.csv` holds invented practice queries from the RA training materials, so the scripts can be run end to end.

Real data files (`consensus_codes.csv`, `study2_responses.csv`, etc.) are listed in `.gitignore` and are never committed.
