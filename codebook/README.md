# Codebook

`codebook_levels.csv` lists every human-coded variable and its allowed levels (the same lists that drive the dropdowns in the coding sheet).

| Code | What it captures |
|---|---|
| Clause type | Declarative, polar/wh interrogative, imperative, fragment |
| Primary act | What the speaker is doing: summary, explanation, evaluation of fairness, opinion, prediction, personal advice, verification, clarification, pushback, meta |
| Directness | Direct vs. indirect speech act |
| Presupposition Y/N, trigger type, direction | Whether the query takes something for granted, what triggers it, and which way it leans |
| Leading construction | Tag question, negative polar question |
| Evaluative language: polarity, target | Appraisal-style evaluation and what it's aimed at |
| Partisan term(s) | Loaded terms one side uses (party names alone don't count) |
| Stance disclosure, direction | Whether the user reveals their own view |
| Relation to previous model turn | New topic, continuation, or uptake of the model's wording |
| Confidence (1-3) | Coder confidence |

Status: v0 (pilot). The frozen v1 codebook will be posted on OSF before main coding.
